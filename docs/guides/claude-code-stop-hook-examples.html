Claude Code Stop hook examples: 5 copy-paste hooks (tested)

A Stop hook runs when Claude finishes its answer and is about to hand control back to you. It can let Claude stop, or send it back to work with a reason. Five small hooks, each tested by piping in the JSON Claude Code sends.

How a Stop hook works

Claude Code sends a JSON object on stdin with session_id, transcript_path, cwd, hook_event_name and stop_hook_active. Stop takes no matcher. The exit code decides what happens:

  • exit 0: Claude stops normally.
  • exit 2: Claude is not allowed to stop. stderr is shown to Claude as the reason, and it keeps working.
  • any other code: a non-blocking hook error; Claude stops.

A hook can also print {"decision": "block", "reason": "..."} on stdout with exit 0 (example 3). Always check stop_hook_active. It is true when Claude is already continuing because of a Stop hook; a hook that blocks every time traps Claude in a loop. Register the scripts in .claude/settings.json:

{
  "hooks": {
    "Stop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/tests_must_pass.py", "timeout": 120},
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/notify_done.py"},
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/no_todo_left.py"},
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/commit_reminder.py"},
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/log_stops.py"}
      ]}
    ]
  }
}

Stop fires at the end of every answer, not only at the end of the session, so keep each hook fast. The test hook gets a longer timeout. SubagentStop takes the same input and output for subagents.

1. Don't let Claude finish while tests fail

The most useful Stop hook. Claude says "done", the hook runs the tests, and if they fail Claude gets the failure and goes back to fix it. Swap the command for npm test, go test ./... or whatever your project uses.

import json, subprocess, sys
data = json.load(sys.stdin)
if data.get("stop_hook_active"):
    sys.exit(0)  # already continued once because of this hook: let Claude stop
r = subprocess.run(["python3", "-m", "pytest", "-q", "-x"], cwd=data.get("cwd") or ".",
                   capture_output=True, text=True)
if "No module named pytest" in r.stderr:
    sys.exit(0)  # no pytest here: don't block on a missing tool
if r.returncode not in (0, 5):  # 5 = no tests collected
    tail = "\n".join((r.stdout + r.stderr).strip().splitlines()[-5:])
    print(f"Tests are failing. Fix them before finishing:\n{tail}", file=sys.stderr)
    sys.exit(2)
sys.exit(0)
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 tests_must_pass.py; echo "exit=$?"
Tests are failing. Fix them before finishing:
test_calc.py:3: AssertionError
=========================== short test summary info ============================
FAILED test_calc.py::test_add - assert -1 == 3
!!!!!!!!!!!!!!!!!!!!!!!!!! stopping after 1 failures !!!!!!!!!!!!!!!!!!!!!!!!!!!
1 failed in 0.02s
exit=2
$ # after the fix
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 tests_must_pass.py; echo "exit=$?"
exit=0
$ echo '{"cwd":"'$PWD'","stop_hook_active":true}' | python3 tests_must_pass.py; echo "exit=$?"
exit=0

The stop_hook_active check gives Claude one extra round to fix the tests; after that it may stop and tell you what is still broken. Without it, a test Claude cannot fix would loop forever.

2. Get a desktop notification when Claude is done

Start a long task, switch windows, get pinged when it finishes. Uses osascript on macOS, notify-send on Linux, and the terminal bell elsewhere.

import json, shutil, subprocess, sys
data = json.load(sys.stdin)
msg = f"Claude Code finished in {data.get('cwd', '?')}"
if shutil.which("osascript"):
    subprocess.run(["osascript", "-e", f'display notification "{msg}" with title "Claude Code"'])
elif shutil.which("notify-send"):
    subprocess.run(["notify-send", "Claude Code", msg])
else:
    sys.stderr.write("\a")  # terminal bell as a fallback
sys.exit(0)
$ echo '{"cwd":"/home/me/app"}' | python3 notify_done.py; echo "exit=$?"
exit=0

For the "Claude is waiting for your permission" case, put the same script on the Notification event.

3. Catch new TODO and FIXME lines

Looks only at lines added in the uncommitted diff. If Claude left a TODO, it is asked to finish it or say why it stays. This one uses the JSON output form.

import json, re, subprocess, sys
data = json.load(sys.stdin)
if data.get("stop_hook_active"):
    sys.exit(0)
diff = subprocess.run(["git", "diff", "-U0"], cwd=data.get("cwd") or ".",
                      capture_output=True, text=True).stdout
added = [l[1:].strip() for l in diff.splitlines() if l.startswith("+") and not l.startswith("+++")]
todos = [l for l in added if re.search(r"\b(TODO|FIXME|XXX)\b", l)]
if todos:
    print(json.dumps({"decision": "block",
                      "reason": f"You added {len(todos)} TODO/FIXME line(s), e.g. {todos[0][:80]!r}. "
                                "Finish them or explain why they stay."}))
sys.exit(0)
$ echo "# TODO: handle overflow" >> calc.py
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 no_todo_left.py; echo "exit=$?"
{"decision": "block", "reason": "You added 1 TODO/FIXME line(s), e.g. '# TODO: handle overflow'. Finish them or explain why they stay."}
exit=0
$ git checkout calc.py
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 no_todo_left.py; echo "exit=$?"
exit=0

4. Ask for a commit message before finishing

If the working tree has changes, Claude is asked to summarize them and suggest a commit message, so you can review and commit in one step. It does not commit anything itself.

import json, subprocess, sys
data = json.load(sys.stdin)
if data.get("stop_hook_active"):
    sys.exit(0)
r = subprocess.run(["git", "status", "--porcelain"], cwd=data.get("cwd") or ".",
                   capture_output=True, text=True)
if r.returncode == 0 and r.stdout.strip():
    n = len(r.stdout.strip().splitlines())
    print(f"{n} file(s) are uncommitted. Summarize the change in one line and "
          "suggest a commit message before finishing.", file=sys.stderr)
    sys.exit(2)
sys.exit(0)
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 commit_reminder.py; echo "exit=$?"
1 file(s) are uncommitted. Summarize the change in one line and suggest a commit message before finishing.
exit=2
$ # clean tree
$ echo '{"cwd":"'$PWD'","stop_hook_active":false}' | python3 commit_reminder.py; echo "exit=$?"
exit=0

This fires after every answer that leaves changes. If that is too chatty, use it only in projects where you want one commit per task.

5. Log every finished turn

Appends a timestamp, the session id and the number of user messages so far (read from the transcript) to .claude/sessions.log. Add the log to .gitignore.

import datetime, json, os, sys
data = json.load(sys.stdin)
log = os.path.join(os.environ.get("CLAUDE_PROJECT_DIR", "."), ".claude", "sessions.log")
os.makedirs(os.path.dirname(log), exist_ok=True)
turns = 0
path = data.get("transcript_path")
if path and os.path.exists(path):
    with open(path) as f:
        turns = sum(1 for line in f if '"type":"user"' in line.replace(" ", ""))
with open(log, "a") as f:
    f.write(f"{datetime.datetime.now().isoformat(timespec='seconds')}\t"
            f"{data.get('session_id', '?')}\tuser_messages={turns}\n")
sys.exit(0)
$ echo '{"session_id":"abc123","transcript_path":"'$PWD'/t.jsonl"}' | CLAUDE_PROJECT_DIR=$PWD python3 log_stops.py; echo "exit=$?"
exit=0
$ cat .claude/sessions.log
2026-11-14T17:16:59	abc123	user_messages=2

Before you trust a hook

A hook that crashes exits with 1, which never blocks, so a broken test hook silently lets Claude stop. Test each one by hand like above, then run the free hook_doctor.py on your settings file to catch missing scripts and relative paths. If a hook still doesn't fire, see the 7-step checklist.
