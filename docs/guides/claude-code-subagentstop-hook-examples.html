Claude Code SubagentStop hook examples: check and log every subagent before it reports back (tested)

A SubagentStop hook runs when a subagent (a Task/Agent tool call) finishes, just before its answer goes back to the main Claude. Like a Stop hook, it can send the subagent back to keep working. Five small hooks, each tested by piping in the JSON Claude Code sends.

How a SubagentStop hook works

The JSON on stdin has the common fields (session_id, transcript_path, cwd, hook_event_name) plus stop_hook_active. Recent versions also send fields about the subagent itself, such as agent_id, agent_type and agent_transcript_path; check the hooks reference for your version. The examples read them with .get() so they still work without them.

{"session_id":"s1", "cwd":"/Users/...", "hook_event_name":"SubagentStop", "stop_hook_active":false, "agent_id":"a1", "agent_type":"code-reviewer", "agent_transcript_path":"/tmp/agent-a1.jsonl"}
  • To send the subagent back, print {"decision": "block", "reason": "..."} and exit 0 (or exit 2 with the reason on stderr). The reason is given to the subagent as its next instruction.
  • stop_hook_active is true when the subagent is already continuing because of a stop hook. Always exit early in that case, or a hook that keeps failing will loop forever.
  • Exit 0 with no output lets the subagent finish normally.

Examples 1, 2 and 5 are side effects only and always exit 0. Examples 3 and 4 can block. Register scripts in .claude/settings.json; each example shows its entry.

1. Log every subagent

Appends one line per finished subagent to .claude/subagents.log: time, session id and agent type. A cheap way to see which subagents Claude actually uses.

import datetime, json, os, sys
data = json.load(sys.stdin)
path = os.path.join(data.get("cwd") or ".", ".claude", "subagents.log")
os.makedirs(os.path.dirname(path), exist_ok=True)
stamp = datetime.datetime.now().astimezone().strftime("%Y-%m-%d %H:%M:%S")
agent = data.get("agent_type") or data.get("agent_id") or "subagent"
with open(path, "a", encoding="utf-8") as f:
    f.write(f'{stamp}\t{data.get("session_id", "?")}\t{agent}\n')
sys.exit(0)
{
  "hooks": {
    "SubagentStop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/log_subagent.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 log_subagent.py
$ cat .claude/subagents.log
2026-11-15 07:17:00	s1	code-reviewer

2. Archive the subagent's transcript

The main transcript only shows the subagent's final answer. If your version sends agent_transcript_path, this copies the subagent's full transcript to .claude/transcripts/subagents/. Without it, it does nothing.

import datetime, json, os, shutil, sys
data = json.load(sys.stdin)
src = data.get("agent_transcript_path")  # newer versions only
if not src or not os.path.isfile(src):
    sys.exit(0)  # nothing to archive
dest_dir = os.path.join(data.get("cwd") or ".", ".claude", "transcripts", "subagents")
os.makedirs(dest_dir, exist_ok=True)
stamp = datetime.datetime.now().strftime("%Y%m%d-%H%M%S")
name = data.get("agent_id") or os.path.splitext(os.path.basename(src))[0]
shutil.copy2(src, os.path.join(dest_dir, f"{name}-{stamp}.jsonl"))
sys.exit(0)
{
  "hooks": {
    "SubagentStop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/archive_subagent.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 archive_subagent.py; echo "exit=$?"
exit=0
$ ls .claude/transcripts/subagents
a1-20261115-071700.jsonl
$ echo '{"cwd":"$PWD"}' | python3 archive_subagent.py; echo "exit=$?"   # no subagent transcript: nothing to do
exit=0

3. Make the subagent pass the tests

Runs pytest -q -x when the subagent finishes. If tests fail, the subagent gets the last lines of output and keeps working, so a broken change never reaches the main conversation as "done". It skips when pytest is not installed and when stop_hook_active is set, so it sends a subagent back at most once.

import json, os, shutil, subprocess, sys
data = json.load(sys.stdin)
if data.get("stop_hook_active"):
    sys.exit(0)  # already sent back once: let it finish, never loop
if not shutil.which("pytest"):
    sys.exit(0)  # no test runner here: don't block on a missing tool
cwd = data.get("cwd") or "."
try:
    r = subprocess.run(["pytest", "-q", "-x"], cwd=cwd, capture_output=True, text=True, timeout=120)
except subprocess.TimeoutExpired:
    sys.exit(0)
if r.returncode not in (0, 5):  # 5 = no tests collected
    tail = "\n".join((r.stdout + r.stderr).strip().splitlines()[-15:])
    print(json.dumps({"decision": "block",
                      "reason": "Tests fail. Fix them before you report back:\n" + tail}))
sys.exit(0)
{
  "hooks": {
    "SubagentStop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/subagent_tests.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 subagent_tests.py; echo "exit=$?"   # tests pass: no output
exit=0
$ echo 'def test_bad(): assert 1 == 2' > tests/test_b.py
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 subagent_tests.py
{"decision": "block", "reason": "Tests fail. Fix them before you report back:\n...\nFAILED tests/test_b.py::test_bad - assert 1 == 2\n...\n1 failed, 1 passed in 0.01s"}
$ # same input with "stop_hook_active":true: no output, exit=0

4. Keep a subagent's edits inside allowed folders

Checks git status --porcelain and sends the subagent back if it changed files outside ALLOWED. Useful when you hand a subagent a narrow job ("fix the parser in src/") and don't want it touching config or CI files. .claude/ is allowed so the logs from other hooks don't trigger it.

import json, subprocess, sys
ALLOWED = ("src/", "tests/", ".claude/")  # where subagents may change files
data = json.load(sys.stdin)
if data.get("stop_hook_active"):
    sys.exit(0)  # already sent back once: don't loop
try:
    out = subprocess.run(["git", "status", "--porcelain"], cwd=data.get("cwd") or ".",
                         capture_output=True, text=True, timeout=10).stdout
except (OSError, subprocess.TimeoutExpired):
    sys.exit(0)
outside = [line[3:] for line in out.splitlines() if line[3:] and not line[3:].startswith(ALLOWED)]
if outside:
    print(json.dumps({"decision": "block",
                      "reason": "You changed files outside " + ", ".join(ALLOWED)
                                + ": " + ", ".join(outside) + ". Revert them or explain why in your reply."}))
sys.exit(0)
{
  "hooks": {
    "SubagentStop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/subagent_scope.py"}
      ]}
    ]
  }
}
$ git status --porcelain
?? .claude/
?? src/
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 subagent_scope.py; echo "exit=$?"   # only allowed folders: no output
exit=0
$ echo x > config.yml
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 subagent_scope.py
{"decision": "block", "reason": "You changed files outside src/, tests/, .claude/: config.yml. Revert them or explain why in your reply."}

We caught a bug while testing this one: the first version did not allow .claude/, so the log written by example 1 blocked every subagent. Test hooks together, not just one at a time.

5. Count subagents per session

Keeps a per-session count in .claude/subagent-counts.json and prints a warning to stderr at 20, which shows up in verbose mode (Ctrl+O). Subagents cost tokens; this tells you when a session fans out more than you expected.

import json, os, sys
data = json.load(sys.stdin)
path = os.path.join(data.get("cwd") or ".", ".claude", "subagent-counts.json")
try:
    with open(path, encoding="utf-8") as f:
        counts = json.load(f)
except (OSError, ValueError):
    counts = {}
sid = data.get("session_id", "?")
counts[sid] = counts.get(sid, 0) + 1
os.makedirs(os.path.dirname(path), exist_ok=True)
with open(path, "w", encoding="utf-8") as f:
    json.dump(counts, f, indent=1)
if counts[sid] == 20:
    print(f"20 subagents finished in session {sid}; check .claude/subagent-counts.json", file=sys.stderr)
sys.exit(0)
{
  "hooks": {
    "SubagentStop": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/subagent_count.py"}
      ]}
    ]
  }
}
$ for i in $(seq 20); do echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SubagentStop","stop_hook_active":false,"agent_id":"a1","agent_type":"code-reviewer","agent_transcript_path":"/tmp/agent-a1.jsonl"}' | python3 subagent_count.py; done
20 subagents finished in session s1; check .claude/subagent-counts.json
$ cat .claude/subagent-counts.json
{
 "s1": 20
}

Only for some subagents

SubagentStop has no matcher in most versions, so every hook runs for every subagent. To limit one to a subagent type, check agent_type at the top of the script and exit 0 for the others, for example if data.get("agent_type") != "code-reviewer": sys.exit(0).
