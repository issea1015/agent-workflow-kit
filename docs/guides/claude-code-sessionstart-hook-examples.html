Claude Code SessionStart hook examples: 5 copy-paste hooks (tested)

A SessionStart hook runs when a session begins or resumes. Whatever it prints becomes context Claude sees before your first prompt. Five small hooks, each tested by piping in the JSON Claude Code sends.

How a SessionStart hook works

Claude Code sends a JSON object on stdin with session_id, transcript_path, cwd, hook_event_name and source. source says why the session started:

  • startup: a new session
  • resume: --resume, --continue or /resume
  • clear: after /clear
  • compact: after auto or manual compaction

The optional matcher is matched against source, so you can run a hook only on some of them. With exit 0, anything the hook prints to stdout is added to Claude's context. A hook can also print JSON with {"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "..."}} (example 2). SessionStart cannot block anything; it only adds context, so a failing hook is harmless but also silent. Keep the output short: it is spent on every session. Register the scripts in .claude/settings.json; each example below shows its own entry.

Check the current hooks reference for details; this guide only uses the fields listed above.

1. Inject the git branch and status

Claude starts every session knowing which branch it is on, how dirty the tree is and what the last commits were, without spending a turn on git status. Prints nothing outside a git repo.

import json, subprocess, sys
data = json.load(sys.stdin)
cwd = data.get("cwd") or "."
def git(*args):
    r = subprocess.run(["git", *args], cwd=cwd, capture_output=True, text=True)
    return r.stdout.strip() if r.returncode == 0 else None
branch = git("rev-parse", "--abbrev-ref", "HEAD")
if branch is None:
    sys.exit(0)  # not a git repo: add nothing
status = git("status", "--porcelain") or ""
changed = len(status.splitlines())
log = git("log", "-3", "--oneline") or "(no commits yet)"
print(f"Git branch: {branch}. Uncommitted files: {changed}.")
print(f"Last commits:\n{log}")
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/git_context.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","cwd":"'$PWD'","hook_event_name":"SessionStart","source":"startup"}' | python3 git_context.py; echo "exit=$?"
Git branch: main. Uncommitted files: 2.
Last commits:
bd1fa1e first
exit=0
$ echo '{"cwd":"/tmp"}' | python3 git_context.py; echo "exit=$?"   # not a repo
exit=0

2. Load your project notes (JSON output form)

Keeps a NOTES.md (or TODO.md) with "what I was doing, what is next". The matcher includes compact so the notes come back after Claude's context is compacted. Only the first 40 lines are used.

import json, os, sys
data = json.load(sys.stdin)
cwd = data.get("cwd") or "."
for name in ("NOTES.md", "TODO.md"):
    path = os.path.join(cwd, name)
    if os.path.isfile(path):
        with open(path, encoding="utf-8", errors="replace") as f:
            text = "".join(f.readlines()[:40])  # cap what goes into context
        out = {"hookSpecificOutput": {
            "hookEventName": "SessionStart",
            "additionalContext": f"Project notes from {name} (first 40 lines):\n{text}"}}
        print(json.dumps(out))
        break
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"matcher": "startup|clear|compact", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/load_notes.py"}
      ]}
    ]
  }
}
$ echo '{"cwd":"'$PWD'","source":"startup"}' | python3 load_notes.py; echo "exit=$?"
{"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "Project notes from NOTES.md (first 40 lines):\nRemember: use uv\nNext: fix login\n"}}
exit=0

3. Warn about missing tools and environment variables

Tells Claude up front that node or DATABASE_URL is missing, so it says so instead of failing three commands later. Edit the two lists for your project. Silent when everything is present.

import json, os, shutil, sys
json.load(sys.stdin)  # input not needed here
need_tools = ["git", "node", "python3"]
need_vars = ["DATABASE_URL", "API_BASE_URL"]
missing = [t for t in need_tools if not shutil.which(t)]
missing += [f"${v}" for v in need_vars if not os.environ.get(v)]
if missing:
    print("Environment check: missing " + ", ".join(missing) +
          ". Tell the user before running anything that depends on them.")
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"matcher": "startup", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/check_env.py"}
      ]}
    ]
  }
}
$ echo '{}' | python3 check_env.py; echo "exit=$?"
Environment check: missing $DATABASE_URL, $API_BASE_URL. Tell the user before running anything that depends on them.
exit=0
$ echo '{}' | DATABASE_URL=x API_BASE_URL=y python3 check_env.py; echo "exit=$?"
exit=0
$ # PATH without git and node
Environment check: missing git, node, $API_BASE_URL. Tell the user before running anything that depends on them.

4. Add the date and time zone

Models do not reliably know today's date. This one-liner of context helps with "this week", log timestamps and changelog entries. It also echoes the source it received.

import datetime, json, sys
data = json.load(sys.stdin)
now = datetime.datetime.now().astimezone()
print(f"Session source: {data.get('source', '?')}. "
      f"Current local time: {now.strftime('%Y-%m-%d %H:%M')} {now.tzname()} (UTC{now.strftime('%z')}).")
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"matcher": "startup|resume|clear", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/date_context.py"}
      ]}
    ]
  }
}
$ echo '{"source":"startup"}' | python3 date_context.py; echo "exit=$?"
Session source: startup. Current local time: 2026-11-14 18:18 UTC (UTC+0000).
exit=0

5. Show the latest changelog and last failing tests

Surfaces the top of CHANGELOG.md and, if pytest left a cache, how many tests failed in the last run. Both are cheap file reads; no tests are executed at startup.

import json, os, sys
data = json.load(sys.stdin)
cwd = data.get("cwd") or "."
parts = []
cl = os.path.join(cwd, "CHANGELOG.md")
if os.path.isfile(cl):
    with open(cl, encoding="utf-8", errors="replace") as f:
        parts.append("Top of CHANGELOG.md:\n" + "".join(f.readlines()[:12]).strip())
lf = os.path.join(cwd, ".pytest_cache", "v", "cache", "lastfailed")
if os.path.isfile(lf):
    try:
        failed = list(json.load(open(lf)))
    except ValueError:
        failed = []
    if failed:
        parts.append(f"{len(failed)} test(s) failed in the last pytest run, e.g. {failed[0]}")
if parts:
    print("\n\n".join(parts))
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"matcher": "startup|resume", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/recent_changes.py"}
      ]}
    ]
  }
}
$ echo '{"cwd":"'$PWD'","source":"startup"}' | python3 recent_changes.py; echo "exit=$?"
Top of CHANGELOG.md:
# Changelog
## 1.2.0
- added foo

1 test(s) failed in the last pytest run, e.g. tests/test_a.py::test_x
exit=0

Use several together

Put multiple entries in the same SessionStart array, or several matcher groups. Their output is combined into the session's context.
