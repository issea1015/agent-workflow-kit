Claude Code SessionEnd hook examples: log, archive and clean up when a session ends (tested)

A SessionEnd hook runs once when a Claude Code session ends: you exit, run /clear, log out, or the session stops for another reason. It cannot stop the session from ending, so it is the place for cleanup and record keeping. Five small hooks, each tested by piping in the JSON Claude Code sends.

How a SessionEnd hook works

Besides the common fields (session_id, transcript_path, cwd, hook_event_name), the JSON on stdin has reason:

{"session_id": "abc123", "transcript_path": "~/.claude/projects/.../abc123.jsonl",
 "cwd": "/Users/...", "hook_event_name": "SessionEnd", "reason": "prompt_input_exit"}
  • reason says why the session ended, for example clear (you ran /clear), logout, prompt_input_exit (you exited at the prompt) or other. Check the hooks reference for the current list; the examples below just record it, or filter on it inside the script.
  • The session is already ending, so the hook cannot block it and its output is not shown to Claude. Write what you want to keep to a file.
  • transcript_path still points at the full session transcript, a JSONL file with one entry per line.

All five examples are side effects only and always exit 0. To bring what they save back into the next session, print the file from a SessionStart hook (see the end of this guide). Register scripts in .claude/settings.json; each example shows its entry.

The transcript format is internal and may change, so examples 2 and 4 read it defensively. Transcripts can contain secrets and code: git-ignore .claude/transcripts.

1. Log every session

Appends one tab-separated line per session to .claude/sessions.log: time, session id, end reason and transcript size. A cheap way to see how long and how often you work with Claude in a project.

import datetime, json, os, sys
data = json.load(sys.stdin)
path = os.path.join(data.get("cwd") or ".", ".claude", "sessions.log")
os.makedirs(os.path.dirname(path), exist_ok=True)
size = 0
t = data.get("transcript_path")
if t and os.path.isfile(t):
    size = os.path.getsize(t)
stamp = datetime.datetime.now().astimezone().strftime("%Y-%m-%d %H:%M:%S")
with open(path, "a", encoding="utf-8") as f:
    f.write(f'{stamp}\t{data.get("session_id", "?")}\t{data.get("reason", "?")}\t{size} bytes\n')
sys.exit(0)
{
  "hooks": {
    "SessionEnd": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/log_session_end.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"prompt_input_exit"}' | python3 log_session_end.py
$ echo '{"session_id":"s2","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"clear"}' | python3 log_session_end.py
$ cat .claude/sessions.log
2026-11-15 03:16:32	s1	prompt_input_exit	653 bytes
2026-11-15 03:16:32	s2	clear	653 bytes

2. Archive the transcript

Copies the transcript to .claude/transcripts/<session>-<time>-end.jsonl so the full conversation stays with the project. If the transcript is missing, it does nothing.

import datetime, json, os, shutil, sys
data = json.load(sys.stdin)
src = data.get("transcript_path")
if not src or not os.path.isfile(src):
    sys.exit(0)  # nothing to archive
dest_dir = os.path.join(data.get("cwd") or ".", ".claude", "transcripts")
os.makedirs(dest_dir, exist_ok=True)
stamp = datetime.datetime.now().strftime("%Y%m%d-%H%M%S")
shutil.copy2(src, os.path.join(dest_dir, f'{data.get("session_id", "session")}-{stamp}-end.jsonl'))
sys.exit(0)
{
  "hooks": {
    "SessionEnd": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/archive_transcript.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"prompt_input_exit"}' | python3 archive_transcript.py; echo "exit=$?"
exit=0
$ ls .claude/transcripts
s1-20261115-031632-end.jsonl
$ echo '{"cwd":"$PWD","reason":"other"}' | python3 archive_transcript.py; echo "exit=$?"   # no transcript: nothing to do
exit=0

3. Delete scratch files

If you ask Claude to keep throwaway files in .claude/scratch, this removes the folder when the session ends, so old drafts never leak into the next one.

import json, os, shutil, sys
data = json.load(sys.stdin)
scratch = os.path.join(data.get("cwd") or ".", ".claude", "scratch")
if os.path.isdir(scratch):
    shutil.rmtree(scratch, ignore_errors=True)
sys.exit(0)
{
  "hooks": {
    "SessionEnd": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/clean_scratch.py"}
      ]}
    ]
  }
}
$ ls .claude/scratch
a
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"prompt_input_exit"}' | python3 clean_scratch.py; echo "exit=$?"
exit=0

4. Save tool-use stats for the session

Counts your typed prompts and Claude's tool calls by tool name, and writes them to .claude/last-session.md. Useful when you are tuning permissions: the tools Claude calls most are the ones worth an allow rule.

import collections, json, os, sys
data = json.load(sys.stdin)
prompts, tools = 0, collections.Counter()
t = data.get("transcript_path")
if t and os.path.isfile(t):
    with open(t, encoding="utf-8") as f:
        for line in f:
            try:
                entry = json.loads(line)
            except ValueError:
                continue  # the transcript format is internal: skip what we can't read
            content = (entry.get("message") or {}).get("content")
            if entry.get("type") == "user" and isinstance(content, str):
                prompts += 1
            elif entry.get("type") == "user" and isinstance(content, list):
                prompts += any(isinstance(c, dict) and c.get("type") == "text" for c in content)
            elif entry.get("type") == "assistant" and isinstance(content, list):
                tools.update(c.get("name", "?") for c in content
                             if isinstance(c, dict) and c.get("type") == "tool_use")
path = os.path.join(data.get("cwd") or ".", ".claude", "last-session.md")
os.makedirs(os.path.dirname(path), exist_ok=True)
with open(path, "w", encoding="utf-8") as f:
    f.write(f'Last session ({data.get("reason", "?")}): {prompts} prompts, {sum(tools.values())} tool calls\n')
    f.writelines(f"- {name}: {n}\n" for name, n in tools.most_common())
sys.exit(0)
{
  "hooks": {
    "SessionEnd": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/session_stats.py"}
      ]}
    ]
  }
}

5. Record uncommitted git changes

Runs git status --porcelain and, if the tree is dirty, saves it to .claude/uncommitted.txt. A clean tree removes the old note. Next session you (or Claude) see right away what was left unfinished.

import json, os, subprocess, sys
data = json.load(sys.stdin)
cwd = data.get("cwd") or "."
path = os.path.join(cwd, ".claude", "uncommitted.txt")
try:
    out = subprocess.run(["git", "status", "--porcelain"], cwd=cwd, capture_output=True,
                         text=True, timeout=10).stdout
except (OSError, subprocess.TimeoutExpired):
    sys.exit(0)  # not a git repo or git missing: nothing to save
if out.strip():
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8") as f:
        f.write("Uncommitted changes when the last session ended:\n" + out)
elif os.path.exists(path):
    os.remove(path)  # clean tree: drop the stale note
sys.exit(0)
{
  "hooks": {
    "SessionEnd": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/save_uncommitted.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"prompt_input_exit"}' | python3 save_uncommitted.py; echo "exit=$?"
exit=0
$ cat .claude/uncommitted.txt
Uncommitted changes when the last session ended:
?? app.py
$ rm app.py; echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"SessionEnd","reason":"prompt_input_exit"}' | python3 save_uncommitted.py; ls .claude/uncommitted.txt   # clean tree: note removed
ls: cannot access '.claude/uncommitted.txt': No such file or directory

Bring it back next session

A SessionStart hook's stdout is added to Claude's context. Print the notes from examples 4 and 5 there, and Claude starts the next session knowing what was left unfinished. The SessionStart guide has a tested script that prints a notes file; point it at .claude/uncommitted.txt.

Before you trust a hook

Test each one by hand like above, then run the free hook_doctor.py on your settings file to catch missing scripts and relative paths. Hooks that copy transcripts handle sensitive data, so audit them: the agent-hook-audit tool is free, and the agent-config-audit Apify actor checks your whole setup at once.
