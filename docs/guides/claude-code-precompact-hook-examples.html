Claude Code PreCompact hook examples: back up and carry context across /compact (tested)

A PreCompact hook runs right before Claude Code compacts the conversation, either when you type /compact or when the context window fills up. It is your last chance to save what the summary may drop. Five small hooks, each tested by piping in the JSON Claude Code sends.

How a PreCompact hook works

Besides the common fields (session_id, transcript_path, cwd, hook_event_name), the JSON on stdin has trigger and custom_instructions:

{"session_id": "abc123", "transcript_path": "~/.claude/projects/.../abc123.jsonl",
 "cwd": "/Users/...", "hook_event_name": "PreCompact",
 "trigger": "manual", "custom_instructions": "keep the deploy decisions"}
  • trigger is manual (you ran /compact) or auto (the context window was full). The matcher is matched against it, so "matcher": "auto" runs a hook only on automatic compaction.
  • custom_instructions is the text you typed after /compact; it is empty for automatic compaction.
  • transcript_path points at the session transcript, a JSONL file with one entry per line. It still holds the full conversation when the hook runs.

The examples below are side effects only: they save files and always exit 0, so they never get in the way of compaction. To bring saved context back after compaction, pair them with a SessionStart hook using the compact matcher (example 5). Register scripts in .claude/settings.json; each example shows its entry.

Check the current hooks reference for details; this guide only uses the fields listed above. The transcript format is internal and may change, so example 4 reads it defensively.

1. Back up the full transcript before it is compacted

Copies the transcript to .claude/transcripts/<session>-<time>-<trigger>.jsonl, so the full conversation is still on disk after the summary replaces it. Transcripts can contain secrets and code, so git-ignore the folder.

import datetime, json, os, shutil, sys
data = json.load(sys.stdin)
src = data.get("transcript_path")
if not src or not os.path.isfile(src):
    sys.exit(0)  # nothing to back up
dest_dir = os.path.join(data.get("cwd") or ".", ".claude", "transcripts")
os.makedirs(dest_dir, exist_ok=True)
stamp = datetime.datetime.now().strftime("%Y%m%d-%H%M%S")
name = f'{data.get("session_id", "session")}-{stamp}-{data.get("trigger", "x")}.jsonl'
shutil.copy2(src, os.path.join(dest_dir, name))
sys.exit(0)
{
  "hooks": {
    "PreCompact": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/backup_transcript.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"PreCompact","trigger":"manual","custom_instructions":"keep the deploy decisions"}' | python3 backup_transcript.py; echo "exit=$?"
exit=0
$ ls .claude/transcripts
s1-20261114-221713-manual.jsonl
$ echo '{"cwd":"$PWD","trigger":"auto"}' | python3 backup_transcript.py; echo "exit=$?"   # no transcript: nothing to do
exit=0

2. Log every compaction

Appends one tab-separated line per compaction to .claude/compactions.log: time, trigger, transcript size and your /compact instructions. If you see many auto lines, your sessions are running long and it may be time to split work or trim CLAUDE.md.

import datetime, json, os, sys
data = json.load(sys.stdin)
path = os.path.join(data.get("cwd") or ".", ".claude", "compactions.log")
os.makedirs(os.path.dirname(path), exist_ok=True)
size = 0
t = data.get("transcript_path")
if t and os.path.isfile(t):
    size = os.path.getsize(t)
stamp = datetime.datetime.now().astimezone().strftime("%Y-%m-%d %H:%M:%S")
note = (data.get("custom_instructions") or "").replace("\n", " ")
with open(path, "a", encoding="utf-8") as f:
    f.write(f'{stamp}\t{data.get("trigger", "?")}\t{size} bytes\t{note}\n')
sys.exit(0)
{
  "hooks": {
    "PreCompact": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/log_compact.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"PreCompact","trigger":"manual","custom_instructions":"keep the deploy decisions"}' | python3 log_compact.py
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"PreCompact","trigger":"auto","custom_instructions":""}' | python3 log_compact.py
$ cat .claude/compactions.log
2026-11-14 22:17:19	manual	493 bytes	keep the deploy decisions
2026-11-14 22:17:19	auto	493 bytes

3. Keep only the newest backups (auto compaction only)

Backups add up. This one deletes all but the newest 10 files in .claude/transcripts. The entry below also shows the matcher: the backup (example 1) and the prune both run on auto only, in the same group. Hooks that match run in parallel, so the prune may see the folder before the new backup lands; that only means it keeps 11 for a moment.

import glob, json, os, sys
KEEP = 10  # newest backups to keep
data = json.load(sys.stdin)
folder = os.path.join(data.get("cwd") or ".", ".claude", "transcripts")
files = sorted(glob.glob(os.path.join(folder, "*.jsonl")), key=os.path.getmtime, reverse=True)
for old in files[KEEP:]:
    os.remove(old)
sys.exit(0)
{
  "hooks": {
    "PreCompact": [
      {"matcher": "auto", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/backup_transcript.py"},
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/prune_backups.py"}
      ]}
    ]
  }
}
$ ls .claude/transcripts | wc -l
13
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"PreCompact","trigger":"manual","custom_instructions":"keep the deploy decisions"}' | python3 prune_backups.py; echo "exit=$?"
exit=0
$ ls .claude/transcripts | wc -l
10

4. Save your recent requests as a handoff note

Summaries sometimes lose the exact wording of what you asked. This hook reads the transcript, keeps your last 5 typed prompts (it skips tool results and lines it cannot parse), and writes them to .claude/handoff.md.

import json, os, sys
N = 5  # how many of your recent prompts to keep
data = json.load(sys.stdin)
prompts = []
t = data.get("transcript_path")
if t and os.path.isfile(t):
    with open(t, encoding="utf-8") as f:
        for line in f:
            try:
                entry = json.loads(line)
            except ValueError:
                continue
            if entry.get("type") != "user":
                continue
            content = (entry.get("message") or {}).get("content")
            if isinstance(content, list):  # skip tool results, keep text parts
                content = " ".join(c.get("text", "") for c in content
                                   if isinstance(c, dict) and c.get("type") == "text")
            if isinstance(content, str) and content.strip():
                prompts.append(content.strip().replace("\n", " ")[:300])
path = os.path.join(data.get("cwd") or ".", ".claude", "handoff.md")
os.makedirs(os.path.dirname(path), exist_ok=True)
with open(path, "w", encoding="utf-8") as f:
    f.write("Recent requests before compaction:\n")
    f.writelines(f"- {p}\n" for p in prompts[-N:])
sys.exit(0)
{
  "hooks": {
    "PreCompact": [
      {"hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/save_handoff.py"}
      ]}
    ]
  }
}
$ cat /tmp/t.jsonl   # test transcript: 3 prompts, 1 tool result, 1 bad line
{"type":"user","message":{"role":"user","content":"Add a --dry-run flag to deploy.py"}}
{"type":"assistant","message":{"role":"assistant","content":[{"type":"text","text":"Sure."}]}}
{"type":"user","message":{"role":"user","content":[{"type":"tool_result","tool_use_id":"t1","content":"ok"}]}}
{"type":"user","message":{"role":"user","content":[{"type":"text","text":"Keep the old behaviour as default"}]}}
not json
{"type":"user","message":{"role":"user","content":"Now write tests for it"}}
$ echo '{"session_id":"s1","transcript_path":"/tmp/t.jsonl","cwd":"$PWD","hook_event_name":"PreCompact","trigger":"manual","custom_instructions":"keep the deploy decisions"}' | python3 save_handoff.py; echo "exit=$?"
exit=0

5. Restore the note after compaction (SessionStart)

When compaction finishes, Claude Code fires SessionStart with source set to compact. A SessionStart hook's stdout is added to Claude's context, so this one prints the handoff note back in. Register it under SessionStart with the compact matcher.

import json, os, sys
data = json.load(sys.stdin)
path = os.path.join(data.get("cwd") or ".", ".claude", "handoff.md")
if not os.path.isfile(path):
    sys.exit(0)
with open(path, encoding="utf-8") as f:
    print(f.read())  # SessionStart stdout is added to Claude's context
sys.exit(0)
{
  "hooks": {
    "SessionStart": [
      {"matcher": "compact", "hooks": [
        {"type": "command", "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/restore_handoff.py"}
      ]}
    ]
  }
}
$ echo '{"session_id":"s1","cwd":"$PWD","hook_event_name":"SessionStart","source":"compact"}' | python3 restore_handoff.py; echo "exit=$?"
Recent requests before compaction:
- Add a --dry-run flag to deploy.py
- Keep the old behaviour as default
- Now write tests for it

exit=0

Before you trust a hook

Test each one by hand like above, then run the free hook_doctor.py on your settings file to catch missing scripts and relative paths. Hooks that copy transcripts handle sensitive data, so audit them: the agent-hook-audit tool is free, and the agent-config-audit Apify actor checks your whole setup at once.
